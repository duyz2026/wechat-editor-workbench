# 公众号编辑工作台

一个**单文件、纯前端**的公众号排版工具：把写好的 Markdown 粘进去，选个主题，点一下，正文就变成能直接粘贴进公众号后台的富文本。

不需要安装，不需要联网，不上传任何东西。

## 怎么用（三步）

1. 打开 `index.html`
2. 点「示例·说明书」或「空白稿」，把左边的内容换成你自己的
3. 点「📋 复制正文」，去公众号后台正文框里 `Ctrl+V`

搞定。配图需要自己在后台插（微信只认自家图床，任何本地图粘贴过去都会变成占位符）。

## 四个文件

| 文件 | 用途 |
|---|---|
| `index.html` | 首页：说明 + 三个入口 |
| `demo-guide.html` | 示例：一篇写公众号排版的说明书，可以直接改成自己的稿子发出去 |
| `demo-long.html` | 示例：一篇长文（约 2000 字），看长文排出来的样子 |
| `demo-blank.html` | 空白稿：什么都不带，直接开写 |

## 它做了什么

- Markdown → 内联样式 HTML（微信后台会剥掉 `<style>`，所以样式全写在标签上）
- 四套主题，一键换
- 复制时自动生成富文本，粘进后台不掉格式
- 字数统计、标题层级、引用块、列表、代码、图片语法都支持
- 「💾 存回原稿」用浏览器的文件系统权限，可以直接写回你磁盘上的 `.md`（Chrome / Edge 支持；Firefox / Safari 会自动降级成下载）

## 它没做什么

- **不联网**。整个工具零外部请求、零 CDN、零统计脚本。
- **不保存**。你写的东西只在当前页面内存里，关掉就没了。想留就存回原稿或自己复制走。
- **不代你发**。发布这一步永远是你自己点。

## 关于「存草稿箱」

在线版这个按钮是灰的，点了会提示「需本机版」。

原因很简单：公众号后台没有开放接口给个人号存草稿，能做到的都是在本机跑一个浏览器桥去点后台页面。每个人的号、每个人的登录态都不一样，这件事没法做成一个公共网页。

你自己要这个能力，就在本机把工具跑起来、配一次浏览器登录态。公共演示版不碰这个。

## 兼容

Chrome / Edge（推荐）、Firefox、Safari 都能用。手机浏览器也能看，但编辑体验不好。
