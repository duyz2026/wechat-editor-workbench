关于这个演示版
  • 页面里的一切都在你自己的浏览器里跑，不上传、不联网、不需要账号。关掉再打开，改过的内容还会问你要不要恢复。

  • 「📂 打开 .md」和「💾 存回原稿」是真能用的：打开你电脑上的稿子，改完直接写回同一个文件，全程不经过任何服务器。

说明它解决了什么

微信只认内联样式，外部 CSS 会被过滤掉

微信编辑器会过滤 <style> 标签和 class，只保留写在 style="" 里的样式。所以渲染时每一条样式都必须内联进标签，否则粘进去就是打回原形。

粘贴会弹「文字对齐异常」，是因为复制了 DOM

在预览区里鼠标全选再 Ctrl+C，浏览器会把计算后的样式一起带走，其中包含 text-align: start，微信不认。这里的做法是不复制 DOM，直接把手写的干净 HTML 写进剪贴板，一个 text-align 都没有。

剪贴板要写 text/html，不能写 text/plain

写纯文本的话，后台显示出来会是一整片 <section style=...> 的标签源码，而不是排版好的正文。

本地图片粘过去一定会裂，这个绕不过

微信只认自家图床。所以复制时所有本地图片统一换成一行红色占位提示「此处插入图片：xxx.png」，去后台对应位置用「图片」按钮补。不假装能自动带过去。

「📥 存草稿箱（需本机版）」为什么在这里点不动

这个按钮要把稿子直接送进公众号后台草稿箱，就必须用你本人的公众号登录态——而每个人登录的是自己的号，一个公开网页替任何人保存都是不合适的。

所以在线演示版里它不会假装成功，点一下会告诉你三件事：这个按钮是干什么的、演示版用什么替代（「📋 复制公众号正文」+ 后台 Ctrl+V，效果一样）、装到自己电脑上之后它怎么用。

换句话说：编辑器主体是通用的，草稿箱这一环是私有的。把这两件事分清楚，比给你一个点了会报错的按钮更有用。
